База university_db.sql состоит из таблиц:

Student_groups(учебные группы):

| Поле         | Тип                  | Описание                                                                      |
| ------------ | -------------------- | ----------------------------------------------------------------------------- |
| group_id     | INT                  | id группы. Является ключевым полем с автоматическим инкрементом               |
| group_name   | VARCHAR(50) NOT NULL | Наименование группы. Является уникальным                                      |
| course_level | TINYINT NOT NULL     | Год обучения. Ограничен с помощью CONSTRAINT chk_course_level_range от 1 до 5 |


Teachers(преподаватели)

| Поле        | Тип                   | Описание                                                               |
| ----------- | --------------------- | ---------------------------------------------------------------------- |
| teacher_id  | INT                   | id преподавателя. Является ключевым полем с автоматическим инкрементом |
| last_name   | VARCHAR(100) NOT NULL | Фамилия преподавателя                                                  |
| first_name  | VARCHAR(100) NOT NULL | Имя преподавателя                                                      |
| middle_name | VARCHAR(100)          | Отчество преподавателя                                                 |
| birth_date  | DATE NOT NULL         | Дата рождения                                                          |
| email       | VARCHAR(100) NOT NULL | Адрес электронной почты. Является уникальным                           |
| phone       | VARCHAR(20)           | Номер телефона. Является уникальным                                    |


Students(студенты)

| Поле            | Тип                   | Описание                                                                         |
| --------------- | --------------------- | -------------------------------------------------------------------------------- |
| student_id      | INT                   | id студента. Является ключевым полем с автоматическим инкрементом                |
| last_name       | VARCHAR(100) NOT NULL | Фамилия студента                                                                 |
| first_name      | VARCHAR(100) NOT NULL | Имя студента                                                                     |
| middle_name     | VARCHAR(100)          | Отчество студента                                                                |
| birth_date      | DATE NOT NULL         | Дата рождения                                                                    |
| email           | VARCHAR(100) NOT NULL | Адрес электронной почты. Является уникальным                                     |
| phone           | VARCHAR(20)           | Номер телефона. Является уникальным                                              |
| group_id        | INT NOT NULL          | id группы. Является внешним ключом, отсылающим к group_id таблицы Student_groups |
| enrollment_year | YEAR NOT NULL         | Год поступления                                                                  |

Subjects(предметы)

| Поле         | Тип                   | Описание                                                             |
| ------------ | --------------------- | -------------------------------------------------------------------- |
| subject_id   | INT                   | id предмета. Является ключевым полем с автоматическим инкрементом    |
| subject_name | VARCHAR(100) NOT NULL | Наименование предмета. Является уникальным                           |
| subject_type | ENUM                  | Тип предмета. ('Math' - математические, 'Humanities' - гуманитарные) |



SubjectAssignments(предметы которые назначены преподавателям)

| Поле          | Тип           | Описание                                                                            |
| ------------- | ------------- | ----------------------------------------------------------------------------------- |
| assignment_id | INT           | id назначения. Является ключевым полем с автоматическим инкрементом                 |
| subject_id    | INT NOT NULL  | id предмета. Является внешним ключом, отсылающим к subject_id таблицы Subjects      |
| teacher_id    | INT NOT NULL  | id преподавателя. Является внешним ключом, отсылающим к teacher_id таблицы Teachers |
| group_id      | INT NOT NULL  | id группы. Является внешним ключом, отсылающим к group_id таблицы Student_groups    |
| academic_year | YEAR NOT NULL | Учебный год.                                                                        |
(subject_id, teacher_id, group_id, academic_year) - составной уникальный ключ для предотвращения дублирования записей. 

Grades(оценки)

| Поле        | Тип              | Описание                                                                            |
| ----------- | ---------------- | ----------------------------------------------------------------------------------- |
| grade_id    | INT              | id оценки. Является ключевым полем с автоматическим инкрементом                     |
| student_id  | INT NOT NULL     | id студента. Является внешним ключом, отсылающим к student_id таблицы Students      |
| subject_id  | INT NOT NULL     | id предмета. Является внешним ключом, отсылающим к subject_id таблицы Subjects      |
| teacher_id  | INT NOT NULL     | id преподавателя. Является внешним ключом, отсылающим к teacher_id таблицы Teachers |
| grade_value | TINYINT NOT NULL | Оценка. Ограничена с помощью CONSTRAINT chk_grade_range от 1 до 5                   |
| grade_date  | DATE NOT NULL    | Дата выставления оценки                                                             |

и нескольких хранимых процедур для человекочитаемого заполнения данных в таблицах SubjectAssignments и Grades: 
```
AddGradeByEmail(
    IN p_student_email VARCHAR(100),   
    IN p_subject_name VARCHAR(100),
    IN p_teacher_email VARCHAR(100),     
    IN p_grade INT
)
```
 - для внесения оценок по уникальным полям студента и преподавателя(email) и уникальному полю предмета(subject_name)
 
```
AddSubjectAssignmentByEmail(
    IN p_teacher_email VARCHAR(100),     
    IN p_subject_name VARCHAR(100),       
    IN p_group_name VARCHAR(50),           
    IN p_academic_year VARCHAR(100)
)
```
 - для назначения предмета для преподавателя по уникальному полю email и уникальному полю предмета subject_name. 

Правила удалений: 

ON DELETE RESTRICT
Нельзя удалить группу, пока в ней числятся студенты. Необходимо сначала перевести или удалить студентов.
Нельзя удалить предмет, пока по нему выставлены оценки. Это нужно для сохранения истории успеваемости.
Нельзя удалить преподавателя, пока он числится выставившим оценки. Так же нужно для истории оценок.

ON DELETE CASCADE
При удалении студента(например, отчислении) автоматически удаляются все его оценки.
При удалении предмета(например, он больше не преподается) автоматически удаляются все его назначения и записи в расписании.
При удалении преподавателя(например, увольнении) автоматически удаляются все его назначения.
При удалении группы(например, расформировании) автоматически удаляются все записи расписания для этой группы.

### Запросы к базе.

1. Вывести список студентов по определённому предмету
```
SELECT DISTINCT s.first_name, s.last_name
FROM Students s
JOIN Grades g ON s.student_id = g.student_id
JOIN Subjects sub ON g.subject_id = sub.subject_id
WHERE sub.subject_name = 'History';
```

2. Вывести список предметов, которые преподаёт конкретный преподаватель
```
SELECT DISTINCT
    sub.subject_name
FROM 
    Subjects sub
JOIN 
    SubjectAssignments sa ON sub.subject_id = sa.subject_id
JOIN 
    Teachers t ON sa.teacher_id = t.teacher_id
WHERE 
    t.first_name = 'Alan' AND t.last_name = 'Turing';
```

3. Вывести средний балл студента по всем предметам
```
SELECT
    s.first_name,
    s.last_name,
    AVG(g.grade_value) AS average_grade
FROM 
    Students s
JOIN 
    Grades g ON s.student_id = g.student_id
WHERE 
    s.first_name = 'Alice' AND s.last_name = 'Johnson'
GROUP BY
    s.student_id;
```
4. Вывести рейтинг преподавателей по средней оценке студентов
```
SELECT
    t.first_name,
    t.last_name,
    AVG(g.grade_value) AS teacher_rating
FROM 
    Teachers t
JOIN
    Grades g ON t.teacher_id = g.teacher_id
GROUP BY
    t.teacher_id, t.first_name, t.last_name
ORDER BY
    teacher_rating DESC;
```

5. Вывести список преподавателей, которые преподавали более 3 предметов за последний год
```
SELECT
    t.first_name,
    t.last_name,
    COUNT(DISTINCT sa.subject_id) AS total_subjects_taught
FROM 
    Teachers t
JOIN 
    SubjectAssignments sa ON t.teacher_id = sa.teacher_id
WHERE
    sa.academic_year = YEAR(CURDATE()) - 1
GROUP BY
    t.teacher_id
HAVING
    total_subjects_taught > 3;
```

6. Вывести список студентов, которые имеют средний балл выше 4 по математическим предметам, но ниже 3 по гуманитарным
```
SELECT
    s.first_name,
    s.last_name
FROM
    Students s
WHERE
    (SELECT AVG(g.grade_value)
     FROM Grades g
     JOIN Subjects sub ON g.subject_id = sub.subject_id
     WHERE g.student_id = s.student_id
       AND sub.subject_type = 'Math') > 4
    AND
    (SELECT AVG(g.grade_value)
     FROM Grades g
     JOIN Subjects sub ON g.subject_id = sub.subject_id
     WHERE g.student_id = s.student_id
       AND sub.subject_type IN ('Humanities')) < 3;
```

7. Определить предметы, по которым больше всего двоек в текущем семестре
```
SELECT
    sub.subject_name,
    COUNT(g.grade_id) AS failing_grades_count
FROM
    Grades g
JOIN
    Subjects sub ON g.subject_id = sub.subject_id
WHERE
    g.grade_value = 2
    AND g.grade_date >= DATE_SUB(CURDATE(), INTERVAL 6 MONTH)
GROUP BY
    sub.subject_id, sub.subject_name
ORDER BY
    failing_grades_count DESC
LIMIT 1;
```

8. Выводить студентов, которые получили высший балл (5) по всем своим экзаменам, и преподавателей, которые вели эти предметы
```
SELECT
    s.first_name AS student_fname,
    s.last_name AS student_lname,
    t.first_name AS teacher_fname,
    t.last_name AS teacher_lname,
    sub.subject_name
FROM
    Students s
JOIN
    Grades g ON s.student_id = g.student_id
JOIN
    Teachers t ON g.teacher_id = t.teacher_id
JOIN 
    Subjects sub ON g.subject_id = sub.subject_id
WHERE 
    g.grade_value = 5
    AND NOT EXISTS (
        SELECT 1
        FROM Grades g2
        WHERE g2.student_id = s.student_id
          AND g2.grade_value < 5
    );
```

9. Просматривать изменение среднего балла студента по годам обучения
```
SELECT
    YEAR(g.grade_date) AS academic_year,
    AVG(g.grade_value) AS year_average_grade
FROM
    Grades g
JOIN
    Students s ON g.student_id = s.student_id
WHERE
    s.first_name = 'Mark' AND s.last_name = 'Zucker'
GROUP BY
    academic_year
ORDER BY 
    academic_year;
```

10. Определить группы, в которых средний балл выше, чем в других, по аналогичным предметам
```
SELECT
    sg.group_name,
    sub.subject_name,
    AVG(g.grade_value) AS avg_group_grade
FROM
    Student_groups sg
JOIN
    Students s ON sg.group_id = s.group_id
JOIN
    Grades g ON s.student_id = g.student_id
JOIN
    Subjects sub ON g.subject_id = sub.subject_id
GROUP BY
    sg.group_name, sub.subject_name, sub.subject_id
HAVING
    AVG(g.grade_value) = (
        SELECT
            MAX(T1.avg_grade)
        FROM (
            SELECT
                g2.subject_id,
                AVG(g2.grade_value) AS avg_grade
            FROM 
                Grades g2
            JOIN 
                Students s2 ON g2.student_id = s2.student_id
            WHERE
                g2.subject_id = sub.subject_id
            GROUP BY 
                s2.group_id, g2.subject_id
        ) AS T1
    )
ORDER BY
    avg_group_grade DESC;
```
